# hts-tick-viewer

TCP 소켓으로 시세 형태의 체결 데이터를 받아 창의 목록에 한 줄씩 쌓아 보여주는
Windows 데스크톱 프로그램이다. 증권사 HTS의 '시간대별 체결' 화면을 아주 작게 흉내 낸다.
클라이언트는 C++/MFC로 만들고, 데이터를 흘려보내는 더미 서버는 Python으로 둔다.
C++과 Win32 소켓, MFC를 직접 익히는 것이 목적이라 코드는 모두 직접 작성한다.

## 폴더 구조

| 폴더 | 용도 |
| --- | --- |
| `server/` | 더미 서버 (Python) |
| `client/` | MFC 클라이언트 (Visual Studio 프로젝트) |
| `notes/` | 배우면서 정리하는 메모 |
| `sandbox/` | 0~1단계 콘솔 습작 (최종 결과물 아님) |

## 진행 단계

- [x] **0. C++ 기초를 콘솔로** — 포인터, `new`/`delete`, 클래스, 소멸자
- [x] **1. 콘솔 TCP 클라이언트** — 길이 프리픽스로 메시지 자르기
- [ ] **2. MFC 창에 List Control** — 가짜 데이터 표시
- [ ] **3. 1과 2 합치기** — 소켓으로 받은 데이터를 목록에 실시간 추가
